# ReviewTap MVP

## Run locally
1. Install Node.js 18+.
2. In this folder run: `npm install`
3. Run: `npm run dev`
4. Open `http://localhost:3000`
5. Demo review page: `http://localhost:3000/r/the-olive-table`
